# 🧠 CortexAI

An AI-powered multi-agent platform built using a **Microservices Architecture**. CortexAI combines multiple specialized AI agents for chatting, code generation, image generation, document analysis, presentations, and more.

🌐 **Live Demo:** https://d18s84dy65fr7b.cloudfront.net/

---

## ✨ Features

- 🤖 AI Chat Assistant
- 💻 AI Code Generation & Code Review
- 📄 AI PDF Generation
- 📊 AI PowerPoint Generation
- 🖼️ AI Image Generation
- 👁️ Image Analysis
- 📚 PDF RAG (Ask questions from PDFs)
- 🔍 AI Search Agent
- 🔐 Firebase Google Authentication
- 💳 Razorpay Payment Integration
- ☁️ AWS S3 File Storage
- 🐳 Dockerized Microservices
- 🚀 CI/CD with GitHub Actions

## 💻 Run Locally

```bash
git clone https://github.com/your-username/CortexAI.git
cd CortexAI

# Install frontend
cd frontend
npm install

# Install backend
cd ../backend
npm install
```

Create the required `.env` files and start the development servers.

```bash
npm run dev
```
